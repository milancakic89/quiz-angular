# FE part of Live quiz using webSockets to play against players in real time
- Playing 1 vs 1 on random oponent search
- Adding friends
- Play agains friend
- Generate your own private or public questions (Public to be approved, private to play with selected friends without approval)
- Win daily rewards + in game rewards base on correct questions answered
- Achievements (How many questions per category were answered)
- Shop - use rewards to buy account customisations (Additional lives, profile border customization etc)
